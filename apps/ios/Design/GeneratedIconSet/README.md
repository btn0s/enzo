# Generated diaper glyphs

Only the diaper-state family is custom. System actions and common concepts continue to use SF Symbols.

The master sheet contains, from left to right:

1. Wet diaper
2. Dirty diaper
3. Wet and dirty diaper

The glyphs were generated in one pass as monochrome, filled, SF Symbols-style artwork. Each variant shares the same base silhouette and changes only its negative-space state marks. The source sprite sheet is preserved here; cropped, template-rendered app assets live in `App/Assets.xcassets`.
